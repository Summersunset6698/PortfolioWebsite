02 — who i am

Curious by nature, engineer by choice.

I'm drawn to the space where software meets the real world — reading live data off a network socket, wiring up wireless peripherals, or mapping how thousands of lines of code actually connect to each other.

I care about building things that are genuinely useful and readable, both in the interface and in the code underneath. Every project is a chance to learn something new: networking, embedded systems, data visualization, or how to put AI to work in practical ways.

Outside of programming, I sketch cars, photograph aircraft and night skies, and dabble in 3D rendering.
