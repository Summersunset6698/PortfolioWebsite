01

Forza Horizon Telemetry Dashboard

Prototype / Functional

A real-time telemetry application that receives and visualizes vehicle data from Forza Horizon, displaying live performance metrics to help players understand driving behavior, vehicle characteristics, and race performance.

Forza provides telemetry data, but the built-in tools are hard to analyze mid-race. This dashboard makes it easy to monitor performance and experiment with tuning changes.

Key Features

  • Real-time telemetry updates
  • Speed, RPM & gear display
  • Throttle / brake visualization
  • Steering angle monitoring
  • Network telemetry listener
  • Custom dashboard interface

Technical Components

  • UDP network communication
  • Telemetry packet decoding
  • Real-time data processing
  • Event-driven programming
  • Data visualization
  • UI design
JavaScriptNode.jsWebSocketsHTML/CSSForza Data Out
Challenges & what I learned

Challenges

  • Decoding telemetry packets correctly
  • Maintaining low-latency updates
  • Managing rapidly changing data
  • Staying readable during gameplay

What I Learned

Hands-on experience with networking, real-time data processing, and dashboard design — plus reinforced concepts in event-driven programming and performance optimization.
