# CodeCraft — Portfolio Website

A modern minimalist website showcasing computer programming projects, artwork, and developer information.

## 📁 Project Structure

```
WebsteImplementation/
├── index.html          # AboutMe page (landing)
├── css/style.css       # Dark minimalist design with purple accents
├── js/script.js        # Gallery filters, lightbox, scroll animations
├── images/             # drawings/, photography/, cgi/
├── PROMPT_LOG.md       # AI workflow log
├── TEST_REPORT.md      # Testing results
└── Pages/
    ├── projects.html   # Computer programming projects
    └── artwork.html    # Creative artwork addon
```

## 🎨 Design Features

- **Color Scheme**: Dark grey (#262626) background, purple (#6f04c7) accents, light white (#e6e6e6) text
- **Typography**: Clean sans-serif fonts for readability
- **Layout**: Minimalist and focused on content
- **Interactions**: Smooth scrolling, hover effects, scroll animations

## 🚀 Features

- Responsive design for all devices
- Smooth scrolling between sections
- Interactive project cards with links to the about page
- Scroll-triggered reveal animations
- Floating decorative elements in hero section
- Background grid pattern for depth
- Dark theme optimized for reduced eye strain

## 🌟 Projects Included

1. **Forza Horizon Telemetry Dashboard** - Real-time UDP telemetry visualizer
2. **Code Node** - Visual node-graph code explorer
3. **Wireless Desk Ecosystem** - Wireless peripherals & embedded systems

Artwork images are loaded from `../Pages/Artwork/` (relative to this folder).

## 🛠️ Technologies Used

- HTML5, CSS3, JavaScript
- Modern responsive design principles
- No external frameworks or libraries
